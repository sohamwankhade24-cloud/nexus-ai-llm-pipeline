# NEXUS AI — THE LLM UNIVERSE
> *"Explore the Intelligence Behind Every Token."*

An extraordinary, visually stunning, fully interactive 3D Large Language Model (LLM) Pipeline Explorer built with futuristic 2040 cyberpunk aesthetics, React, TypeScript, Three.js, React Three Fiber, and Tailwind CSS.

---

## 🌟 Architecture & Highlights

### 1. 🌌 Epic 3D Landing Experience
- **Interactive 3D Neural Cortex**: Parametric dual-hemisphere brain geometry built in Three.js / React Three Fiber with 1,600 synaptic nodes, dynamic axon lines, pulsing quantum core, and cybernetic orbital rings.
- **Floating KaTeX Formulations**: Holographic mathematical badges highlighting attention, positional harmonics, and temperature softmax.
- **Smooth Portal Transition**: "ENTER THE PIPELINE" seamlessly transports the user into the research laboratory.

### 2. ⚡ 5-Stage Interactive Pipeline
1. **01 — TEXT INPUT**:
   - Live editable prompt buffer with character and token telemetry.
   - 4 Curated benchmark presets (Transformer Foundation, Spatial & Physical Syntax, Multi-Head Reality, Consciousness).
   - Hyperparameter controls: **Temperature ($T$)**, **Causal vs. Bidirectional Masking**, and **Attention Filter Threshold**.
2. **02 — TOKENIZATION**:
   - Subword segmentation with Byte-Pair Encoding (BPE).
   - Individual token chips with hex colors, positions, and realistic vocabulary IDs ($1000 \dots 49999$).
   - Token occurrence frequency chart and metadata inspector.
3. **03 — EMBEDDINGS**:
   - **3D Vector Space**: Orbitable, zoomable 3D universe showing tokens as glowing spheres positioned via PCA projections, origin vector rays, and dynamic cosine similarity lines.
   - **2D Tensor Matrix**: SeqLen × 16 dimension continuous weight heatmap.
   - **Positional Encoding Decomposition**: $\mathbf{x}_{\text{final}} = \mathbf{E}_{\text{token}} + \mathbf{PE}_{(\text{pos})}$.
   - **Pairwise Cosine Similarity**: Pairwise angular distance table.
4. **04 — SELF-ATTENTION**:
   - **Interactive 2D Attention Heatmap**: Hoverable cells showing directional attention weights $A_{ij} \in [0, 1]$.
   - **3D Attention Arcs**: Tokens arranged around a holographic pedestal with quadratic Bezier arcs where thickness and glow intensity scale with attention strength.
   - **Multi-Head Decomposition**: Switch between Head 1 (Syntactic), Head 2 (Semantic), Head 3 (Positional), Head 4 (Long-Range), or Average across all heads.
   - **Real Tensor Inspector**: Query ($Q$), Key ($K$), Value ($V$) projections and step-by-step mathematical derivation:
     $$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
5. **05 — NEXT-TOKEN PREDICTION**:
   - Top-5 candidate tokens with realistic probabilities summing to 100%.
   - Shannon entropy metric and reasoning explanation for each candidate.
   - Temperature slider dynamically shaping the probability distribution.
   - **Autoregressive Generation**: "APPEND & CONTINUE GENERATION" appends the predicted token to the prompt sequence and triggers recursive inference.

### 3. 🖥️ Real-Time AI Inference Terminal
- Streams real timestamped pipeline logs for every tensor computation.
- Log level filters: `ALL`, `TENSOR`, `MATH`, `INFO`.
- One-click copy to clipboard and clear actions.

### 4. 📚 Educational Control Centre (Research Archive)
- Interactive theoretical curriculum with KaTeX equations covering:
  - Transformers architecture
  - Byte-Pair Encoding (BPE)
  - Semantic vector spaces
  - Sinusoidal positional encodings
  - Query, Key & Value (QKV) projections
  - Scaled dot-product attention
  - Temperature-scaled Softmax
  - Autoregressive decoding loops

### 5. 🔊 Holographic Audio Synthesizer
- Built using the Web Audio API with zero external audio dependencies.
- Synthesizes futuristic harmonic pings, neural transition sweeps, and execution chimes with a mute/unmute toggle.
